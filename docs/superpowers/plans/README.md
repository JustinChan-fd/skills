# Archived plans

Everything in this directory is **history, not live work.** These plans were
written for the `alfred/` and `harness-*-core/` skills, which were deleted from
this repo on 2026-08-04 (285 files, 66,596 lines). Every file path they name
(`harness-core/tools/…`, `alfred/lib/…`, `.alfred/config.json`) is gone.

They are kept because the *reasoning* is still worth reading — several of them
record measurements that were expensive to obtain and are not derivable from the
code that survived. But do not treat any of them as a task list, and do not
follow their file paths.

What actually survived that era is `skill-observability/`, and it carries its own
documentation: `README.md` for the design and the rejected alternatives,
`COST.md` for the cache/attribution measurements, `METRICS.md` for what every
number means. The defect-level lessons travelled as tests, not prose — see
`skill-observability/test/regressions.test.mjs`, one anchor per real defect.
